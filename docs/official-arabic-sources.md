# المصادر العربية الرسمية داخل MMC

تتضمن بوابة العطاءات الدولية مصدرين إقليميين موثقين. المصدر السعودي هو منصة اعتماد الرسمية للمنافسات الحكومية عبر https://tenders.etimad.sa/، مع بوابة اعتماد العامة عبر https://etimad.sa/. المصدر الإماراتي هو منصة المشتريات الرقمية الاتحادية المرتبطة بوزارة المالية عبر https://procurement.gov.ae/page.aspx/en/rfp/request_browse_public، مع صفحة تعريف المنصة في موقع الوزارة عبر https://mof.gov.ae/en/public-finance/government-procurement/digital-procurement-platform/.

تظهر هذه المصادر داخل MMC مع الدولة والروابط الرسمية ومفتاح التصفية. عند حجب صفحة المصدر بتسجيل الدخول أو التحقق الآلي، لا تستورد MMC إعلاناً غير متحقق؛ تعرض المصدر الرسمي مباشرة حتى تبقى حالة العطاء وتفاصيله قانونية ودقيقة.
