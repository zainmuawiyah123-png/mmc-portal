# MMC AI — سجل النواقص ومعايير الإغلاق
تاريخ المراجعة: 2026-11-10
الفرع: feature/mmc-ai-construction-intelligence
الحالة: سجل قبول تنفيذي؛ لا يعني أن البنود المفتوحة قد نُفذت.

## قواعد القبول
1. لا يُعد وجود شاشة أو زر أو endpoint دليلاً على اكتمال المحرك الهندسي.
2. كل وظيفة يجب أن تعمل على ملف فعلي، وتنتج نتيجة قابلة للتتبع مع مصدرها وافتراضاتها وحدودها.
3. لا تعتمد كمية آلية نهائياً قبل مراجعتها ومقارنتها بعينة Ground Truth أعدّها/راجعها مهندس مختص.
4. لا تُستخدم بيانات تجريبية على أنها بيانات مشروع حقيقي.
5. جميع الملفات والنتائج محكومة بعضوية المشروع والصلاحيات وسجل التدقيق.
6. لا دمج إلى الفرع الرئيسي ولا نشر Render قبل اجتياز الاختبارات وموافقة المالك.

## حالة الموجود فعلياً بعد فحص الكود
| المجال | الموجود فعلياً | النقص الذي يمنع الإغلاق |
|---|---|---|
| مساحة المشروع | مشاريع وأعضاء وأدوار وعزل وصول أساسي | إدارة دورة حياة المشروع، دعوات/إزالة أعضاء، صلاحيات دقيقة واختبارات شاملة |
| صور الموقع | رفع الصور، سجل الصور، اختيار الغلاف، وصف وتاريخ | معاينة/تحسين الصور، معرض مراحل متكامل، ربط الصور بالأنشطة والموقع والتقارير |
| استقبال المستندات | رفع PDF/DXF وصور وGLB مع تخزين خاص وchecksum | DWG، TIFF، ملفات متعددة، فحص عميق للملفات، مهام معالجة غير متزامنة |
| PDF | فحص بنية أولي عبر pdf-preflight فقط | استخراج النصوص والإحداثيات والمسارات والصور، OCR، دعم التدوير وCropBox، viewer overlay |
| DXF | حصر هندسي أولي لكيانات مدعومة مع وحدات وINSERT محدودة | توسيع الكيانات والبلوكات والتحقق من الوحدات والطبقات، اختبارات CAD مرجعية، مراجعة وتصدير |
| DWG | لا يوجد محلل DWG | مسار تحويل/تكامل مرخص ومختبر مع الحفاظ على الوحدات والطبقات والكتل |

| BOQ والتكلفة | إدخال بنود وكميات وأسعار وتجميع تقديري | ربط takeoff ببنود BOQ، قواعد القياس، مراجعة الأسعار، العملات والضرائب، تصدير Excel/PDF |
| BIM | رفع IFC/GLB، عرض GLB، جرد أولي لعناصر ووحدات IFC، سجل ملاحظات | هندسة IFC وخصائصها، عرض IFC/تنسيق موحد، محرك clash detection، تقارير BCF/تصدير |
| البرنامج الزمني | أنشطة وعلاقات وحساب CPM وتحديث التقدم | Baseline، تواريخ فعلية، مقارنة مخطط/فعلي، تحليل تأخير، استيراد/تصدير Primavera/MS Project |
| العقود والمطالبات | تسجيل أحداث وبيانات FIDIC أولية وأثر وقت/كلفة | مستودع عقود ومراسلات، استخراج شروط ومراجع دقيقة، تحليل استحقاق مدعوم بالمستندات، سجل زمني وإشعارات |
| المخاطر | سجل مخاطر ودرجة احتمال×أثر وخطة تخفيف | ربط المخاطر بالمخططات والأنشطة والعقود، مؤشرات مبكرة، سجل تغيّر وتقارير |
| مساعد AI | إجابات قواعدية تستند إلى سجلات المشروع | نموذج توليدي حقيقي مع RAG للمستندات، إحالات صفحة/فقرة، منع التخمين، اختبارات تقييم وأمن |
| التقارير | لوحة تنفيذية مجمعة أولية | تقارير دورية احترافية، PDF/Excel، رسوم واتجاهات، سجل إصدار واعتماد |
| اللغات وتجربة الاستخدام | واجهة عربية أساسية وبعض عناصر اللغة | ترجمة كاملة عربية/إنجليزية، RTL/LTR شامل، جوال وإتاحة واختبارات الواجهة |

## ترتيب التنفيذ وبوابات الإغلاق

### A — الأساس التشغيلي والأمان
- توحيد API errors والتحقق من المدخلات والملفات.
- اختبارات عزل لمشروعين، مستخدمين، وأدوار القراءة/التحرير/المراجعة.
- التحقق من checksum عند كل قراءة وتحميل، وسياسة احتفاظ ونسخ احتياطي.
- معالجة غير متزامنة مع حالات queued/running/succeeded/failed وإعادة المحاولة.

### B — PDF Drawing Intelligence
- اختيار مكتبة PDF بعد إثبات قدرة وترخيص واضحين.
- استخراج النص والمواضع والمسارات والصور وبيانات الصفحة.
- OCR للملفات الممسوحة مع إحداثيات وثقة لكل كلمة.
- عارض PDF مع طبقات نتائج وقياس يدوي ومعايرة موثقة.
- اختبارات PDF مرجعية: متعدد الصفحات، تدوير، CropBox، عربي، ممسوح، مشفر، تالف.

### C — CAD وTakeoff
- دعم DXF موسع وDWG عبر محرك/تحويل مرخص.
- دعم LINE/POLYLINE/ARC/CIRCLE/SPLINE/HATCH/BLOCK/INSERT وطبقاتها حيث يثبت الدعم.
- معايرة ووحدات صريحة؛ رفض الكميات عند غموض المقياس.
- overlay لكل عنصر محسوب، معادلة، وحدة، مصدر، افتراضات، تحذيرات وحالة مراجعة.
- ربط النتائج بـ BOQ وتصدير Excel/PDF.

### D — BIM
- تحليل هندسة IFC وخصائص العناصر والعلاقات والوحدات.
- عارض ثلاثي الأبعاد موحد للنماذج المدعومة.
- محرك تعارضات هندسي مع قواعد tolerances وإظهار العنصرين والموقع والتخصص.
- سجل issue workflow وتقارير قابلة للتصدير؛ لا إعلان كشف تعارض قبل اختباره على نماذج مرجعية.

### E — التخطيط والعقود والمخاطر والذكاء الاصطناعي
- Baseline ومقارنة مخطط/فعلي وتحليل المسار الحرج والتأخير.
- تحليل مستندات العقد والمطالبات مع إحالات قابلة للتحقق إلى الصفحات والفقرات.
- ربط المخاطر بالأنشطة والمستندات والأحداث.
- مساعد RAG لا يجيب عن حقائق المشروع إلا من مصادر المشروع، ويصرح عند غياب الدليل.

### F — التقارير والتكامل والواجهة
- تقارير تنفيذية وفنية ومالية دورية، مع PDF/Excel.
- ترجمة عربية/إنجليزية كاملة وتجاوب الهاتف.
- مراجعة تصميم NeuBuild AI ومطابقة عناصره بصرياً ووظيفياً دون نسخ علامة أو ادعاء تكامل غير موجود.
- اختبار end-to-end من رفع الملف حتى اعتماد النتيجة والتقرير.

## تعريف الاكتمال النهائي
لا يغلق أي مجال إلا عند توفر: (1) تنفيذ فعلي، (2) API محمي، (3) واجهة مستخدم تعمل، (4) اختبارات آلية، (5) عينة قبول هندسية مرجعية، (6) سجل مصدر وافتراضات، (7) دليل تشغيل، (8) عرض ناجح على نسخة معاينة. البنود التي تتطلب ملفات/بيانات هندسية من المالك تُوسم بوضوح "بانتظار عينة قبول" ولا تُعلن مكتملة.

## قيود لا يجوز تجاوزها
- لا تعديل لبوابات MMC/TenderWise الحالية خارج نطاق MMC AI.
- لا نشر على Render أو دمج إنتاجي قبل موافقة صريحة.
- لا أرقام أو صور أو نتائج تجريبية تظهر كأنها بيانات فعلية.
- لا إصدار كميات نهائية أو استحقاقات تعاقدية آلية دون مراجعة بشرية موثقة.
