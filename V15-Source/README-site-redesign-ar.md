# MMC AI — تحديث الموقع والواجهة إلى مستوى احترافي

**الإصدار:** v13 · **التاريخ:** 18 نوفمبر 2026
**الأساس:** v12 (BIM · الكميات · 4D/5D · تصدير Excel · استيراد BOQ · الألمنيوم · المواصفات · المخاطر)

---

## ١) ما تغيّر — باختصار

أُعيد بناء **الشكل والتجربة والموقع** بالكامل. **لم تُحذف أي وظيفة**، ولم يُغيَّر أي معرّف (id) أو مسار API أو حقل نموذج. كل ما في v12 يعمل كما هو.

| ما كان | ما صار |
|---|---|
| لا موقع تعريفي — الواجهة فقط | موقع من ٦ صفحات: رئيسية + منتج + تسعير، بالعربية والإنجليزية |
| لوحة عمل داكنة بلا هوية بصرية موحّدة | نظام تصميم واحد: ألوان، مسافات، خطوط، حالات |
| لا صفحة تسعير | صفحة تسعير بباقتين واختيار خدمتين مجاناً |
| لا تنقل على الجوال (الشريط الجانبي مخفي بلا بديل) | درج تنقل منزلق مع حجاب وزر قائمة |
| صور بطاقات الأنشطة من روابط خارجية (تنكسر بلا إنترنت) | ٥ صور محلية مولّدة داخل الحزمة |
| عناوين عربية تتداخل مع صندوق النموذج | قياس عربي مضبوط (حجم ومقياس نص) |
| جدول مقارنة ينضغط على الجوال | تمرير أفقي بحد أدنى للعرض |

## ٢) الموقع التعريفي — ٦ صفحات

**المسار:** `/mmc-ai/site/`

| الصفحة | المسار | المحتوى |
|---|---|---|
| الرئيسية (EN) | `/mmc-ai/site/` | واجهة رئيسية، كيف يعمل (٤ خطوات)، ٨ قدرات، أرقام الإثبات، جدول مقارنة، دعوة للتسجيل |
| المنتج (EN) | `/mmc-ai/site/product` | ٨ أقسام تفصيلية + قسم «ما لا يفعله» |
| التسعير (EN) | `/mmc-ai/site/pricing` | باقتان، اختيار خدمتين، جدول الأنشطة الثماني، ٦ أسئلة |
| الرئيسية (AR) | `/mmc-ai/site/ar/` | نفس المحتوى بالعربية RTL |
| المنتج (AR) | `/mmc-ai/site/ar/product` | — |
| التسعير (AR) | `/mmc-ai/site/ar/pricing` | — |

**الملفات المشتركة:** `site/assets/site.css` (نظام التصميم) و`site/assets/site.js` (التنقل + اختيار الباقة).

### ما استُخرج من NEUBUILD.AI

درست الصفحة الرئيسية فعلياً واستخرجت ما يجعلها تبدو احترافية:

1. **عنوان رئيسي قصير وحاد** لا يشرح المنتج بل يذكر النتيجة.
2. **سطر توضيحي واحد** يشرح كيف تُنتج النتيجة.
3. **زرّان** — أساسي وثانوي، لا أكثر.
4. **أرقام إثبات** تحت الواجهة مباشرة (لا شعارات عملاء وهمية).
5. **صندوق منتج مرئي** بجانب النص، لا صورة عامة.
6. **شبكة قدرات** بثلاثة أعمدة، كل بطاقة بأيقونة وعنوان وسطرين.
7. **تسلسل خطوات مرقّم** بدل قائمة ميزات.
8. **جدول مقارنة** يضع المنتج مقابل البديل الحالي.
9. **باقة مجانية + باقة مدفوعة** بسعر واحد واضح، لا ثلاث باقات مربكة.
10. **أسئلة شائعة** تُغلق الاعتراضات قبل التسجيل.

**ملاحظة صريحة:** صفحات `/pricing` و`/platform` على موقع المرجع أعادت 404 عند الزيارة. لذلك بُنيت صفحة التسعير على أفضل ممارسات SaaS المعروفة، لا على نسخ صفحة لم أرها.

### الهوية البصرية

- **الخلفية:** `#05080f` (أسود مزرق عميق) مع تدرّجات شعاعية خفيفة.
- **اللوحات:** `#0b1220` بحدود شفافة `rgba(255,255,255,.09)`.
- **اللون المميز:** `#4cc9f0` سماوي، و`#2f8de4` أزرق للتدرّج.
- **النجاح:** `#7cf5c4` · **التحذير:** `#f0b45c`.
- **الخط:** Inter للإنجليزية، Segoe UI/Tahoma للعربية.
- **المسافات:** مقياس واحد `clamp()` يتكيّف مع العرض.
- **الاتجاه:** خصائص منطقية (`margin-inline`, `inset-inline`) فينعكس RTL تلقائياً بلا ملف أنماط ثانٍ.

## ٣) الواجهة الداخلية

**المسار:** `/mmc-ai/` (أو `/mmc-ai/workspace` بعد تسجيل الدخول)

أُضيفت طبقة أنماط واحدة `#mmc-ai-professional-ui` فوق الأنماط القائمة. **لم يُحذف أي عنصر ولم يُغيَّر أي معرّف.**

**ما تحسّن:**
- شريط جانبي ثابت بعرض 264px، عناصر تنقل بارتفاع 42px، وحالة نشطة بشريط جانبي سماوي.
- شريط علوي لاصق بضبابية خلفية.
- مسافات أوسع بين الأقسام، وحدود أوضح بين اللوحات.
- تباين أعلى للتسميات الصغيرة (كانت `#7b8b9b` على `#10243d` — الآن `#7d8fa6` على `#0b1220`).
- جداول برؤوس لاصقة عند التمرير، وصفوف بتظليل عند المرور.
- حقول إدخال بحالة تركيز واضحة (حلقة سماوية).
- **درج تنقل للجوال** — كان الشريط الجانبي يختفي تماماً تحت 700px بلا بديل.

**كل القدرات محفوظة ومُتحقَّق منها آلياً:** ١٤ لوحة، ١٣ رابط تنقل، وسكربتات `mmc-ai-bim-model-engine` و`mmc-ai-four-capabilities` و`mmc-ai-language-switch` كما هي.

## ٤) التشغيل

```bash
unzip mmc-ai-v13.zip && cd v13/server
cp .env.example .env          # اضبط JWT_SECRET
npm install
npm run migrate
npm start                     # المنفذ 3000 افتراضياً
```

ثم افتح:

| الرابط | الصفحة |
|---|---|
| `http://localhost:3000/mmc-ai/site/` | الموقع التعريفي (EN) |
| `http://localhost:3000/mmc-ai/site/ar/` | الموقع التعريفي (AR) |
| `http://localhost:3000/mmc-ai/site/pricing` | التسعير |
| `http://localhost:3000/mmc-ai/` | مساحة العمل |

**مسارات الخادم المضافة** (في `server/src/index.js`، قبل `express.static`):

```
/mmc-ai/site            → mmc-ai/site/index.html
/mmc-ai/site/ar         → mmc-ai/site/ar/index.html
/mmc-ai/site/product    → mmc-ai/site/product.html
/mmc-ai/site/pricing    → mmc-ai/site/pricing.html
/mmc-ai/site/ar/product → mmc-ai/site/ar/product.html
/mmc-ai/site/ar/pricing → mmc-ai/site/ar/pricing.html
```

كل مسار يقبل الصيغتين: بشرطة مائلة ونهايتها. الموقع **عام** (بلا تسجيل دخول)؛ مساحة العمل تبقى محمية كما كانت.

### ما أصلحته بعد رؤيته في المتصفح

1. **العنوان العربي كان يتداخل مع صندوق النموذج.** العربية أعرض من اللاتينية عند الحجم نفسه. خفّضت حجم العنوان العربي إلى `clamp(28px,3.9vw,46px)` وحدّدت مقياسه بـ`19ch`.
2. **٥ صور بطاقات كانت مكسورة** — روابط خارجية (fedes.ca، cloudfront، prescience، supabase، linkedin). ولّدت ٥ صور محلية واستبدلتها. أضفت اختباراً يمنع أي صورة خارجية من العودة.
3. **جدول المقارنة كان ينضغط على الجوال** فتصير العمودان أعمدة نحيلة غير مقروءة. أعطيته حداً أدنى 620px ليمرّر أفقياً.
4. **أزرار الرأس كانت متلاصقة على 390px.** ضيّقت الحشو والمسافات تحت 600px.

## ٦) حدود ما أُنجز — بصراحة

1. **صفحة التسعير معاينة، لا اشتراك.** اختيار الباقة يُسجَّل في الصفحة فقط. **لا تحصيل دفع، ولا تفعيل صلاحيات، ولا ربط ببوابة دفع.** الصفحة تقول ذلك صراحةً في مكانين. ربط Stripe أو ما يعادله عمل لم يُنجز.
2. **الأسعار (٠ $ / ٣٠ $) أرقام عرض.** لم تُشتق من تحليل سوق ولا من تكلفة تشغيل.
3. **لم أستطع زيارة صفحات المنتج والتسعير على NEUBUILD.AI** — أعادت 404. البنية مبنية على الصفحة الرئيسية + ممارسات SaaS، لا على نسخ صفحات لم أرها.
4. **لا مدونة ولا صفحات قانونية** (خصوصية، شروط، ملفات تعريف ارتباط). الموقع التعريفي يحتاجها قبل النشر التجاري.
5. **لا نموذج تواصل ولا تسجيل بريد.** أزرار «ابدأ مجاناً» تنقل إلى مساحة العمل مباشرة.
6. **الواجهة الداخلية بالإنجليزية** بينما الموقع بالعربية والإنجليزية. مبدّل اللغة في الواجهة يترجم النصوص الموجودة في قاموسه فقط، لا كل شيء.
7. **لم أختبر على متصفحات أخرى** (Safari، Firefox) ولا على جهاز حقيقي — الاختبار على Chromium في مساحة العمل عند 1440px و390px.
8. **لا اختبار وصول (a11y) آلي** — أضفت `aria-expanded` و`aria-controls` و`aria-current`، لكن لم يُشغَّل مدقّق مثل axe.
9. **لا اختبار حمل** — لم يُقس الأداء تحت مستخدمين متزامنين.
10. **الصور المولّدة توضيحية**، ليست صور مشاريع حقيقية. بطاقة «Site Progress Photos» ما زالت تستخدم صورة المشروع الأصلية.

**قبل النشر التجاري:** `NODE_ENV=production` + `COOKIE_SECURE=true` + `JWT_SECRET` قوي + HTTPS + نسخ احتياطي مجدول + صفحات خصوصية وشروط.

## ٧) ما لم يتغيّر — وهذا مقصود

كل ما يلي يعمل كما في v12 بالضبط، ومُتحقَّق منه بالاختبارات:

- محرك BIM (٦ أنواع عناصر، IFC4 استيراداً وتصديراً)
- الحصر من النموذج (١٣ قاعدة، ربط المصدر)
- 4D/5D (البرنامج الزمني، منحنى التكلفة، الاعتماد)
- تصدير Excel المعتمد (٥ أوراق، عمود المصدر)
- استيراد BOQ (Excel/CSV، كشف الأعمدة، المطابقة)
- جداول الألمنيوم
- المواصفات والمخاطر (١٤ قاعدة)
- OCR للمخططات الممسوحة
- كل مسارات API وسجلات الاعتماد

**تنبيه مهني:** الكميات والتكاليف آلية أولية. لا تصلح للتسعير أو التوريد أو التعاقد قبل مراجعة مهندس مختص. الاعتماد في النظام يُسجَّل باسم من اعتمد ووقته، لكنه لا يُغني عن التوقيع المهني المعتمد في بلدك.
